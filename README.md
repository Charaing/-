# BOXING VOICE COACH

에어팟을 끼고 샌드백 앞에서 쓰는 한국어 음성 복싱 코치 PWA.
React + TypeScript + Vite + Tailwind CSS. 서버·로그인 없이 동작하고 모든 데이터는 기기(localStorage / IndexedDB)에 저장됩니다.

---

## 1. 실행 방법 (Windows / Mac 공통)

Node.js 18 이상이 필요합니다.

```bash
npm install
npm run dev        # 개발 서버 — http://localhost:5173
npm test           # 단위 테스트 21개
npm run build      # 배포용 빌드 → dist/
npm run preview    # 빌드 결과 미리보기 — http://localhost:4173
```

`npm run dev` 실행 시 터미널에 나오는 `Network: http://192.168.x.x:5173` 주소를 같은 와이파이의 iPhone Safari에서 열면 바로 테스트할 수 있습니다.
단, **HTTP 주소에서는 서비스 워커(오프라인)·마이크 녹음이 동작하지 않습니다.** 실시간 TTS 훈련은 HTTP에서도 됩니다.

## 2. 배포 방법 (HTTPS 필수)

`npm run build` 후 `dist/` 폴더를 정적 호스팅에 올리면 끝입니다. 상대 경로(`base: './'`)로 빌드되므로 하위 경로에 올려도 됩니다.

- **Netlify / Cloudflare Pages / Vercel**: 빌드 명령 `npm run build`, 출력 폴더 `dist`
- **GitHub Pages**: `dist` 내용을 `gh-pages` 브랜치에 올리기
- **임시로 폰에서 HTTPS 테스트**: `npm run preview` 후 `cloudflared tunnel --url http://localhost:4173` → 나온 `https://….trycloudflare.com` 주소를 iPhone에서 열기

## 3. iPhone 홈 화면 설치

1. Safari로 배포 주소 접속
2. 하단 **공유** 버튼 → **홈 화면에 추가**
3. 홈 화면의 BOXING 아이콘으로 실행 → 주소창 없는 전체 화면 앱

앱 안에서도 Safari 탭으로 열려 있으면 설치 안내가 뜨고, 설치 후 실행하면 숨겨집니다.

## 3-1. iPhone 앱(IPA)으로 설치 — 잠금 화면에서도 계속 동작

`ios/` 폴더에 Capacitor 7 기반 네이티브 iOS 프로젝트가 들어 있습니다. 앱 버전에서는 **네이티브 코치 엔진**(`ios/App/App/CoachEnginePlugin.swift`)이 동작합니다.
- 전체 훈련 타임라인을 미리 넘겨받아 iOS 음성 엔진(AVSpeechSynthesizer)으로 직접 읽습니다.
- 백그라운드 오디오 세션을 유지하므로 화면이 잠겨도 타이머·명령·벨이 계속 진행됩니다.
- 전화·알람이나 이어폰 분리 시 자동으로 일시정지하고, 잠금 화면에서 재생/일시정지할 수 있습니다.

IPA는 `.github/workflows/ios-build.yml`(GitHub Actions의 macOS 빌드 서버)이 서명 없이 빌드하고, Windows에서는 Sideloadly로 내 Apple ID로 서명해 설치합니다.
**자세한 절차는 `아이폰_설치_가이드.md`를 보세요.**

Mac이 있다면: `npm install && npm run ios:sync && npx cap open ios` → Xcode에서 Team을 선택하고 실행하면 됩니다.

## 5. 오디오 방식과 실제 제약 (중요)

### 방식 A — 실시간 TTS (기본)
Web Speech API(`speechSynthesis`)로 기기 내장 한국어 음성이 바로 읽습니다. 설정 변경이 훈련 중에도 즉시 반영됩니다.
- 출력 장치는 iOS가 고른 곳(에어팟·블루투스·유선·스피커)으로 나갑니다. 웹페이지는 에어팟 연결 여부를 알 수 없으므로 **설정 → 음성 테스트**로 확인하세요.
- **화면이 꺼지거나 잠기면 Safari가 음성을 멈출 수 있습니다.** 그래서 훈련 중 화면 켜짐 유지(Wake Lock, iOS 16.4+)를 기본으로 켜 둡니다. 지원하지 않는 기기는 설정에서 자동 잠금을 길게 바꾸라고 안내합니다.
- 앱 복귀 시 실제 경과 시간으로 위치를 다시 계산하고, 밀린 명령을 한꺼번에 내보내지 않습니다.

### 방식 B — 연속 오디오 트랙 (잠금 화면용)
훈련 전에 전체 명령 순서를 정하고, 음성 + 무음 + 벨을 **실제 WAV 파일 하나**로 렌더링해 `<audio>`로 재생합니다. Media Session으로 잠금 화면에 제목·재생·일시정지가 표시됩니다. 화면 표시는 오디오 재생 위치를 기준으로 동기화됩니다.

Web Speech API는 음성을 파일로 내보낼 수 없기 때문에, 트랙의 음성은 아래 둘 중 하나로 준비해야 합니다 (**설정 → 연속 오디오 음성 준비**).
1. **내 녹음** — 펀치 9개 + 풋워크 12개(필수), 안내 6개(선택)를 직접 녹음. 앞뒤 무음 자동 제거·음량 정규화. 기기에만 저장, 완전 오프라인.
2. **외부 TTS 서버** — `https://…?text={text}` 형식 주소. CORS 허용 + mp3/wav 응답 필요. 받은 음성은 IndexedDB에 캐시되어 다음부터 오프라인 재사용.

마지막으로 만든 트랙은 저장되어 홈의 “마지막으로 만든 트랙 다시 재생”으로 인터넷 없이 다시 쓸 수 있습니다.
**잠금 상태 재생은 iOS 버전·저전력 모드·다른 앱의 오디오에 따라 멈출 수 있으며 보장하지 않습니다.** 완전한 백그라운드 재생이 필요하면 네이티브 앱이 필요합니다.

### 음악과 함께 쓰기
iOS 오디오 정책상 음성이 나올 때 다른 앱 음악이 멈추거나 작아질 수 있고, 웹페이지는 다른 앱 음량을 조절할 수 없습니다. 음성 테스트로 먼저 확인하세요.
벨·비프음(Web Audio)은 iPhone 무음 스위치가 켜져 있으면 들리지 않을 수 있습니다.

## 6. 오류 처리

| 상황 | 동작 |
|---|---|
| TTS 미지원 / 음성 안 나옴 | 안내 + “음성 다시 시도” 버튼. 타이머와 화면 표시는 계속 진행 |
| `onend` 이벤트 누락 | 예상 길이 기반 안전 타이머로 다음 명령 진행 |
| 한국어 음성 없음 | 홈에 내려받기 경로 안내, 기본 음성으로 읽음 |
| 훈련 중 설정 변경 | 음성·간격·비율은 즉시 반영, 라운드 구조는 세션 동안 고정 |
| 화면 잠금 / 백그라운드 / 전화 | 복귀 시 실제 경과 시간으로 재계산, 놓친 안내는 소리 없이 건너뜀 / 트랙 모드는 외부 일시정지를 감지 |
| 새로고침·앱 종료 | 1초마다 세션 저장 → 다음 실행 시 “이어서 하기”(일시정지 상태) 또는 “기록만 저장” |
| 브라우저 재생 차단 | 시작은 항상 터치 이벤트 안에서 음성 잠금 해제, 트랙은 “재생 시작” 버튼 |
| 음성 중첩 | 한 번에 하나만 발화, 라운드 안내가 명령보다 우선(진행 중 명령 취소) |
| 라운드 경계 | 남은 시간 안에 끝나지 않을 명령은 내보내지 않음 |
| 트랙 생성 실패 | 원인(누락된 녹음 목록 등) 표시 + 다시 시도 / 실시간 TTS로 시작 |
| 일시정지·재개 반복 | 세대 번호로 이전 음성 콜백 무효화, 일시정지 시간은 시계에서 제외 |

## 8. 테스트 결과

**단위 테스트 (vitest) — 25개 전부 통과** (네이티브 타임라인 플래너 4개 포함)
- 콤비: 정확히 100개 / 중복 없음 / 허용 코드만, 5·6 거부 / 100개 × 읽기 3종 × 스타일 3종 × 스탠스 2종 문구 생성 / 난이도 3단계 존재 / 풋워크 12개
- 음성 문구: 명세서 예시(원투!, 잽, 잽, 투 / 원투, 왼훅, 투 / 원, 투, 쓰리, 투 / 정식 명칭), 사우스포, 원투 묶음 규칙
- 스케줄러: 난이도 필터, 제외 콤비 미선택, 최근 5개 미반복(300회), 믹스 비율 75:25(4000회 측정 70~82%), 풋워크·커스텀 모드 범위, 긴 콤비 연속 억제, 랜덤 간격 5.6~8.4초
- 타이머: 구간 표·경계, 설정 보정, 일시정지 시간 제외

**브라우저 E2E (Chromium, iPhone 크기 390×844, TTS 모의 객체)**
- 2R × 30초 / 휴식 15초 / 준비 3초 실제 실행: 준비 안내 → 카운트다운 → 시작! → 명령(콤비·풋워크·연결·코칭 큐) → 십 초 남았습니다! → 라운드 종료! 휴식. → 삼·이·일 → 두 번째 라운드, 시작! → 훈련 종료. 수고하셨습니다. → 요약 화면·기록 저장 확인
- 일시정지 4초 동안 발화 0건, 재개 시 “계속!” 후 이어짐, 종료 시각이 일시정지 시간만큼 정확히 밀림
- 연속 트랙 모드: 스텁 TTS 서버로 WAV 생성 → 재생 → 화면 명령·타이머가 재생 위치와 동기화, 일시정지 동작
- 새로고침 후 “이어서 하기” → 같은 남은 시간(00:55)에서 일시정지 상태로 복구
- 콘솔 오류 0건

**실기기에서 직접 확인해야 하는 항목** (이 환경에서는 iPhone 실기기·에어팟 테스트 불가)
- 에어팟 출력, 실제 한국어 음성 품질, 홈 화면 설치 후 실행, 잠금 화면 재생 지속 여부, Wake Lock 동작
